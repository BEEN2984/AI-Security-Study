## 1. 자산

- 사용자 파일, 자격증명, 메일 발송 권한
- 도구실행권한
- 에이전트 실행 흐름

## 2. 신뢰 경계

| 단계               | 가정                                                            | 신뢰도      |
| ------------------ | --------------------------------------------------------------- | ----------- |
| 사용자 입력        | 사용자가 직접 입력하지만 안전하지 않다고 가정                   | 비교적 신뢰 |
| Agent Code         | 에이전트 동작 규칙과 Runtime 로직                               | 신뢰        |
| LLM 출력           | LLM이 출력하는 메시지                                           | 미신뢰      |
| TOOL Result        | 파일이나 외부 데이터에서 들어온 결과가 다시 LLM 입력으로 들어감 | 미신뢰      |
| sandbox/ 파일 내용 | 공격자가 악의적인 명령 삽입 가능한 파일                         | 미신뢰      |

## 3. 공격자 능력

- 할수 있는 것
  - 외부데이터에 악성 코드 삽입
  - 정상적인 문서 내용 사이에 악의적인 프롬프트 삽입
  - 특정 URL이나 도구를 파일에 포함
  - 반복 호출을 유도하여 tool call을 폭주
- 못하는 것
  - 코드 변경
  - 시스템 프롬프트를 직접 변경
